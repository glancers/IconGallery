# IconGallery 产品需求文档

## 产品目标

IconGallery 是一个无需构建即可部署的图标选型工作台，帮助用户统一搜索、预览、比较和复制多个图标库的资源与用法。

## 核心用户

- 需要为 Web 或客户端界面选择图标的设计师和开发者。
- 需要通过 CLI 搜索和获取图标的 AI Agent。

## 核心能力

- 聚合 28 个图标库并提供跨库搜索。
- 支持中文、拼音、英文和同义词搜索。
- 支持尺寸、颜色和图标风格预览。
- 支持收藏比较及 HTML、React、Vue、SVG 等用法复制。
- 支持深浅主题、URL 状态分享和本地偏好保存。
- 图标库加载时，固定卡片网格共同组成心跳或小恐龙像素动画，数据就绪后整页一次性显示真实图标。
- 支持零构建部署到 GitHub Pages。

## 本次变更

优化图标库加载反馈：每张骨架卡片作为一个像素，整片网格播放从中心向外逐环扩散、到边缘再收回的心跳波纹；加载完成后不额外等待，整片骨架一次性替换为真实图标网格。

## 验收标准

- GitHub Pages 项目子路径下可正确加载页面、样式和脚本。
- 原有搜索、切库、预览、收藏、复制和主题功能保持可用。
- 加载骨架与真实卡片尺寸一致，切换期间不发生布局跳动。
- 快速切库、加载失败或窗口缩放时，不残留上一轮动画。
- 减少动态效果模式下显示静态图案并立即完成替换。
- 本地通过 HTTP 静态服务器即可运行，无需安装依赖或执行构建。
