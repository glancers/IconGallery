# IconGallery UI 设计文档

## 视觉原则

- 以中性灰为基础，靛蓝色用于选中、聚焦和主要操作状态。
- 支持明亮与黑暗主题，主题值由 `css/style.css` 中的 CSS 变量统一管理。
- 图标卡片保持统一尺寸、间距和交互反馈，方便跨库比较。
- 加载动效沿用卡片本身作为像素，不在卡片内叠加独立插画或 spinner。

## 布局

- 桌面端使用左侧图标库与预览设置、右侧搜索和图标网格的双栏结构。
- 移动端左侧栏变为抽屉，使用统一的半透明模糊遮罩。
- 图标详情和收藏比较使用居中弹窗。

## 组件规范

- 图标卡片：展示图标、名称和收藏入口。
- 像素骨架卡片：尺寸与图标卡片一致，默认低对比度；活动像素整卡使用低透明度靛蓝底色与边框。
- 分段选择器：切换图标风格和代码类型。
- 色板与滑杆：调整颜色、尺寸、描边和字重。
- Toast：反馈复制结果。
- 弹窗关闭按钮统一使用 `×`。

## 响应式与可访问性

- 图标网格按可用宽度自动调整列数。
- 加载图案按当前列数居中并在窄屏裁切，窗口变化时重新计算。
- 交互元素提供 hover、focus-visible 和 aria-label 状态。
- 文本输入框支持 Cmd/Ctrl+A 全选。
- 遵循 `prefers-reduced-motion`，减少动态效果时停用循环帧。
