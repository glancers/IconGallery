# IconGallery 测试用例

## 静态资源

| 编号 | 场景 | 预期结果 |
|---|---|---|
| ST-01 | 通过 HTTP 打开 `/index.html` | 页面返回 200 |
| ST-02 | 请求 `/css/style.css` | 返回 200 且页面样式生效 |
| ST-03 | 请求 `/js/app.js` | 返回 200 且交互逻辑启动 |
| ST-04 | 部署到 GitHub Pages 项目子路径 | 相对资源路径正常加载 |

## 核心功能

| 编号 | 场景 | 预期结果 |
|---|---|---|
| FN-01 | 切换图标库 | 标题、设置和图标网格同步更新 |
| FN-02 | 搜索中文、拼音或英文 | 当前库和其他图标库展示相关结果 |
| FN-03 | 点击图标 | 打开详情弹窗并展示预览与代码标签页 |
| FN-04 | 修改详情弹窗中的颜色或风格 | 仅更新弹窗预览和代码，不影响全局设置 |
| FN-05 | 收藏并打开对比 | 收藏内容正确持久化和展示 |
| FN-06 | 点击复制 | 内容写入剪贴板并显示提示 |
| FN-07 | 切换深浅主题 | 页面主题切换并在刷新后保持 |
| FN-08 | 在输入框按 Cmd/Ctrl+A | 当前输入框内容被全选 |

## 像素网格加载

| 编号 | 场景 | 预期结果 |
|---|---|---|
| LD-01 | 慢速网络下首次加载图标库 | 卡片网格播放从中心向外扩散再收回的心跳波纹 |
| LD-02 | 检查加载骨架结构 | 每张卡片只代表一个像素，卡片内部没有独立小动画 |
| LD-03 | 图标数据加载成功 | 不额外等待，骨架一次性替换为真实图标网格 |
| LD-04 | 加载时快速切换图标库 | 上一图标库的动画任务停止，不覆盖当前网格 |
| LD-05 | 加载失败后重试 | 失败面板正常显示；重试后网格按真实宽度重新生成 |
| LD-06 | 加载中改变窗口宽度 | 像素矩阵按新列数重新居中且无越界卡片 |
| LD-07 | 开启减少动态效果 | 显示静态像素图案，加载完成后整页一次性替换 |
